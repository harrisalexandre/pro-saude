# UX e Acessibilidade

## Princípio central

> Se uma pessoa de 65+ precisa pedir ajuda para entender a interface, a experiência precisa ser revista.

## Diretrizes

### Clareza

- uma ação principal por tela;
- textos curtos;
- labels explícitos;
- pouca informação concorrendo pela atenção.

### Toque

- áreas de interação amplas;
- controles destacados;
- evitar ações pequenas ou muito próximas.

### Legibilidade

- tipografia grande;
- contraste adequado;
- hierarquia visual clara;
- não depender somente de cor.

### Feedback

Ações importantes devem fornecer retorno visível: remédio confirmado, consulta compreendida, SOS acionado, erro de cadastro e sessão encerrada.

### Movimento

Animações são auxiliares. A informação não deve depender delas e deve existir uma experiência equivalente para preferência de movimento reduzido.

## Separação de experiências

```text
IDOSO
  ↓
mínimo necessário

FAMÍLIA / ESF / DOUTOR
  ↓
mais dados + configuração + gestão
```
